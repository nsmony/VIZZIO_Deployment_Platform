The VIZZIO Deployment Platform supports the controlled publication, access, and
delivery of software deployments. This guide brings together the technical,
administrative, operational, and handover knowledge needed to run it safely.

## Who this guide is for

- **Administrators** managing users, groups, deployments, versions, and settings.
- **Developers** maintaining the frontend, backend, database, or launcher.
- **Deployment engineers** preparing hosts and publishing releases.
- **Maintainers and support teams** diagnosing incidents and taking ownership.

## Documentation map

Use Getting Started for environment preparation, System Design for architecture,
Administration for daily platform management, Development for implementation
evidence, Launcher for the Windows client, Operations for publishing, and
Reference for handover and troubleshooting.

## Platform at a glance

The **frontend** provides the browser-based administration experience. The
**backend** exposes APIs, applies authentication and business rules, and works
with the database and deployment storage. The **launcher** is a Windows client
that discovers and downloads authorized versions. A **hosted PC** runs the
production services and supporting software. The deployment workflow moves a
validated package from preparation through registration, access assignment,
download, verification, and release monitoring.
